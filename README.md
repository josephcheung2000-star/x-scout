# x-scout
Scripts for a personal crypto/investment research scout: X timeline fetch (headless browser), primary-source feeds
(Binance/OKX notices, SEC EDGAR, Polymarket, Hyperliquid), rule-based triage, a lead ledger with price tracking,
paper-trading of alert plans, and a listing backtest. No credentials in this repo - they are supplied at run time.
Research tooling only; not investment advice.
